22.Slope 

斜率
其求取公式為:
m = (y1 - y0) / (x1 - x0)

其中:
1.當 y1 - y0 = 0 的時候 斜率為0 -> 此線段為水平線
2.當 x1 - x0 = 0 時 目前數學上分母不可為0 不在實數範圍認定內 -> 此線段為鉛直線

求出以上情況時候 則該斜率不存在

輸入:
四個正整數 分別為y1、y0、x1、x0

輸出:
判斷該斜率不為 0 且斜率存在時輸出 m
當該斜率不存在時 則輸出"the slope is undefined"

範例輸入:
2
5
7
8

範例輸出:
3.0
