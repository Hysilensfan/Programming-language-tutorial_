7.Small dictionary attck 

小型字典攻擊

今天 你是一位怪客/駭客
想對主播「我的世界浩晨」各帳號的密碼進行字典攻擊
而這次 你想使用經典的 rockyou.txt 進行攻擊

這邊提供 rockyou.txt 前10行:
rockyou_simple

撰寫程式碼 該程式碼可以對輸入進行檢查

輸入:
一個正整數  d 以及 d 個測試資料s

輸出:
判斷輸入對應的輸出是否被攻擊
被攻擊即輸出 True ;反之 False

限制:
1.114514 >= d >= 0
2.114514 >= 字串s的長度 >= 1

提示:
1.輸出支援字串(string)與布林值(boolean)
2.可以用一個容器(contain)將 wordlist 儲存起來
3.如果使用線性搜尋（例如:逐個比對） 時間複雜度是 O(n)
