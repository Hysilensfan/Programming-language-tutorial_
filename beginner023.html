23.Specific Prime 

特別質數
特別質數 由阿拉特尼茲．達茲霍茲提出(沒這人 我編的)

給定一個正整數 N 若 N 同時符合以下三項條件 則可稱 N 為特別質數

1.平方根小數特性(Sqrt)
計算 √N 的值 取其小數點後三位 並依照四捨五入規則處理
若處理後得到的三位數字為 A、B、C 則必須滿足以下條件：
B - A = C - B

也就是說 這三個數字必須形成等差數列
如:
Ex1.√x = ... .123
因為：
2 - 1 = 3 - 2
故 x 符合條件
Ex2.√y = ... .630
因為：
3 - 6 = 0 - 3
故 y 符合條件

2.N 不可以是快樂數字(Happy number)

快樂數字的判定方式如下：
重複將 N 的每一位數字平方後加總 直到結果為 1 或進入循環(Fall in loop)
若最後得到 1 則 N 為快樂數字
若進入循環且無法得到 1 則 N 不是快樂數字

3.N 必須是一個質數(Prime number)

而質數的因數只會有 1 與 自己

輸入:
一個正整數d

輸出:
從 1 ~ d(包含 d) 的所有特別質數

範例輸入:
123

範例輸出:
17
113

限制:
1.65535 >= d >= 17
2.測試資料一定都是數字 不會有字串 無須特地驗證
